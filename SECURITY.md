# Security

Please use [GitHub's private vulnerability reporting](https://github.com/felixubl/ablage/security/advisories/new)
for vulnerabilities. Include the affected commit or version, steps to reproduce, and
the expected impact. Use synthetic files and remove credentials or private document text.

Do not put an unpatched vulnerability or sensitive data in a public issue. Ordinary bugs
without a security impact can go in the [issue tracker](https://github.com/felixubl/ablage/issues).

This is a small project. Security fixes target the latest version on `main`; older
versions do not have a separate maintenance branch. There is no guaranteed response time.

For where document text and credentials are stored, see [Privacy and backups](docs/privacy.md).
